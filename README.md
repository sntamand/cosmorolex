# COSOROLEX WATCHES — Luxury Watch Ecommerce

A responsive, professional ecommerce front-end for watches and accessories, inspired by the supplied Cosorolex Watches design.

## Included
- Responsive luxury ecommerce homepage
- Product catalog with search and brand filtering
- Add-to-cart functionality with localStorage
- Cart modal and totals
- Crypto checkout UI for BTC, ETH, USDT and USDC
- Accessory and brand sections
- Newsletter form
- No backend required for the demo

## Run
Open `index.html` directly in a browser, or serve the folder with any static server:

```bash
python -m http.server 8000
```

Then open http://localhost:8000

## Production crypto payments
The checkout currently demonstrates the UI only. For real payments, connect the `payNow()` function in `app.js` to your server-side payment provider (for example Coinbase Commerce or another compliant crypto processor). Never put private wallet keys or payment secrets in browser JavaScript.

## Product images
The included CSS uses stylized watch illustrations so the project works immediately without external image assets. Replace `.mini-watch` and accessory backgrounds with licensed product photography for production.
