# Cosmorolex Watches

A responsive, single-page watch and accessories storefront.

## Run it
Open `index.html` directly in a browser, or serve the folder with any static web server.

## Included
- Responsive luxury-style storefront
- Product filtering
- Watch and accessory catalog
- Shopping bag with localStorage persistence
- Newsletter form
- Mobile navigation
- Placeholder product artwork generated entirely with CSS

## Going live
Connect the checkout button to Stripe Checkout or another payment provider, add a real product database, replace placeholder product artwork with licensed product photography, and add your shipping/tax/returns policies.

Important: verify that the Cosmorolex name, logo, product designs, and domain do not infringe existing trademarks or other intellectual-property rights before commercial launch.


## Admin dashboard
Open `admin.html` to view the demo administration dashboard. It includes overview metrics, product management, orders, customers, and settings. The demo login accepts any email/password; implement real server-side authentication before deployment.
